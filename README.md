### What I Learned

The biggest takeaway from this project was working with Figma. I followed the design exactly, using both the documentation and provided examples. The tricky part was recognizing and converting the shadow parameters into CSS `box-shadow`. Luckily, I found a [convenient converter](https://www.figma.com/community/plugin/1374511779922909714/figma-drop-and-inner-shadow-to-css-box-shadow) specifically for this purpose.

```css
.card {
    ...
    box-shadow: 0px 25px 25px 0px rgba(0, 0, 0, 0.05);
}
```

### Useful resources

- [Figma Shadow Plugin](<(https://www.figma.com/community/plugin/1374511779922909714/figma-drop-and-inner-shadow-to-css-box-shadow)>) - This helped me accurately replicate shadows from Figma designs. I really liked this tool and will continue using it in future projects.
